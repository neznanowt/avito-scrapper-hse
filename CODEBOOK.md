# Кодбук: описание полей базы

База — SQLite (`data/realty.sqlite`). Время везде ISO 8601 по Москве (`2026-11-11T14:04:00+03:00`).
Логические поля — 0/1.

Источник для Авито:
- **JSON** — встроенный в страницу карточки `window.__staticRouterHydrationData`, ветка
  `loaderData.*.buyerItem` (ниже — путь от `buyerItem`);
- **Параметры** — блок «О квартире» (`paramsDto.items`), заголовок параметра → значение;
- **О доме** — `item.houseParams.data.items`;
- **Выдача** — карточка на странице поиска;
- **Сборщик** — поле ведёт сам сборщик.

## listings — одна строка на объявление (последнее известное состояние)

### Идентификация и служебные поля

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| platform | текст | сборщик | `avito` (позже `cian`, `domclick`) |
| listing_id | текст | `item.id` | ID объявления на площадке |
| url | текст | `item.url` / выдача | адрес карточки без параметров |
| first_seen_at | время | сборщик | когда объявление впервые попало в нашу базу (замена даты публикации, которую Авито не показывает) |
| last_seen_at | время | сборщик | когда последний раз видели в выдаче |
| missing_since | время | сборщик | первый полный обход выдачи, в котором объявления не было; NULL — есть в выдаче |
| status | текст | сборщик / JSON | `active`; `closed` — карточка открывается, но снята (`closedItem`, `isClosed`, `isArchived`, `isExpired`…); `removed` — HTTP 404 |
| status_detail | текст | `closedItemStatus` | формулировка Авито для снятых |
| status_checked_at | время | сборщик | когда последний раз открывали карточку |
| last_parsed_at | время | сборщик | время последнего разбора карточки |
| parse_source | текст | сборщик | `hydration` — встроенный JSON; `dom` — запасной разбор HTML (фото могут быть неполными) |
| parser_version | текст | сборщик | версия парсера |
| raw_path | текст | сборщик | путь к сохранённой странице относительно `data/` |

### Цена

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| title | текст | `item.title` | заголовок, напр. «2-к. квартира, 50 м², 1/7 эт.» |
| price | целое | `item.price` / выдача | цена предложения, ₽ (последняя известная) |
| price_per_m2 | число | расчёт | `price / area_total` |
| price_history_records | целое | `priceHistory.recordsCount` | сколько записей в истории цены на Авито (1 — цена не менялась) |
| price_increased | 0/1 | `priceHistory.hasIncreased` | цену когда-либо повышали |

### Квартира

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| rooms | целое | параметры «Количество комнат» | число комнат; студия = 0; свободная планировка = NULL |
| rooms_raw | текст | то же | значение как на сайте («2», «студия», «своб. планировка», «10 и больше») |
| is_studio, is_free_layout | 0/1 | то же | студия / свободная планировка |
| area_total, area_living, area_kitchen | число | «Общая / Жилая площадь», «Площадь кухни» | м² |
| floor, floors_total | целое | «Этаж» («1 из 7»), «Этажей в доме» | этаж и этажность |
| ceiling_height | число | «Высота потолков» | м |
| bathroom | текст | «Санузел» | раздельный / совмещенный / … |
| balcony | текст | «Балкон или лоджия» | как на сайте |
| room_layout | текст | «Тип комнат» | изолированные / смежные / … |
| windows | текст | «Окна» | во двор / на улицу / … |
| **renovation** | текст | «Ремонт» | **поле «ремонт» от продавца**: требует ремонта / косметический / евро / дизайнерский |
| sale_method | текст | «Способ продажи» | свободная / альтернативная |
| params_json | JSON | все параметры | все пары «параметр: значение» из «О квартире», включая неразобранные (мебель, техника, стоимость ремонта по оценке Авито и т.п.) |

### Дом

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| house_type | текст | «Тип дома» | кирпичный / панельный / монолитный / … |
| build_year | целое | «Год постройки» | |
| house_series | текст | «Серия дома» | если указана |
| passenger_lifts, freight_lifts | целое | «Пассажирский / Грузовой лифт» | число лифтов |
| house_params_json | JSON | «О доме» | все параметры дома как на сайте |
| house_id | текст | `houseId` | ID дома в каталоге Авито — для сравнения квартир внутри дома (расширение 8) и дедупликации |
| address_id | текст | `addressId` | ID адреса Авито |

### Место

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| address | текст | `item.geo.address` | адрес как на сайте |
| lat, lon | число | `item.geo.coords` | координаты дома (не путать с `item.location.coords` — это центр города) |
| metro_name | текст | `item.geo.references[0].content` | ближайшая станция |
| metro_walk_min, metro_walk_max | целое | `…afterWithIcon.text` («6–10 мин.») | пешком до метро, мин |
| metro_distance_m | целое | `…after` («500 м», «1,6 км») | расстояние до метро, м |
| metro_json | JSON | `item.geo.references` | все станции: name, time, distance, line_colors |

Района на странице нет; его нужно вычислять по координатам.

### Продавец

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| seller_type | текст | `seller.labels.nominative` | «Частное лицо», «Агентство», … как на сайте |
| is_company | 0/1 | `isCompany` | продавец — компания |
| is_shop | 0/1 | `item.shop.isShop` | у продавца магазин на Авито (обычно агентство) |
| seller_key | текст | `item.userId` | солёный SHA-256 от ID продавца: группирует объявления одного продавца, не раскрывая его. Имена и телефоны не сохраняются |

### Текст, фото, спрос

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| description | текст | `item.description` | полное описание |
| photo_count | целое | `item.imageUrls` | число фото (видео не считаются) |
| layout_count | целое | `item.realtyLayoutUrls` | число отдельных изображений планировки |
| views_total, views_today | целое | `viewStat` | просмотры всего / сегодня на момент разбора (динамика — в `observations`) |
| date_label | текст | `item.sortFormatedDate` | подпись даты на сайте («сегодня в 14:04»). Это дата последнего **поднятия**, а не публикации |
| date_label_at | время | расчёт | та же дата в абсолютном виде |
| expires_at | время | `item.finishTime` | до какого числа оплачено размещение |

### Флаги отбора

Ничего не удаляется: отбор делается на этапе анализа по этим флагам.

| Поле | Тип | Источник | Описание |
|---|---|---|---|
| is_secondary | 0/1 | `item.flags.isSecondarySell` | вторичный рынок |
| is_development | 0/1 | `item.flags.isDevelopmentSell` | продажа от застройщика (исключаем) |
| is_apartments | 0/1 | параметры и заголовок | встречается «апартамент…» (исключаем) |
| is_share | 0/1 | заголовок | продаётся доля (исключаем) |
| category_id, micro_category_id | целое | `item.categoryId`, `microCategoryId` | рубрика Авито (24 — квартиры) |

## observations — панель наблюдений

Одна строка на объявление × день × источник.

| Поле | Описание |
|---|---|
| platform, listing_id | объявление |
| obs_date | дата наблюдения (МСК) |
| source | `search` — видели в выдаче; `item` — открывали карточку |
| observed_at, run_id | время и номер запуска |
| price | цена в этот день — по ней строится собственная история цены |
| views_total, views_today | только для `source = item` |
| status | статус в этот момент |
| search_position | позиция в выдаче (номер страницы × 60 + место) |

## photos — фото объявлений

| Поле | Описание |
|---|---|
| platform, listing_id, url | ключ; `url` — размер 640×480, с которого делается уменьшенная копия |
| url_large | наибольший доступный размер (1280×960) |
| position | порядок в галерее (0 — обложка); планировки — с 100 |
| kind | `photo` или `layout` |
| is_current | 1 — фото есть в последней версии объявления; 0 — продавец его убрал |
| first_seen_at, last_seen_at | когда фото было в объявлении |
| local_path | путь к файлу относительно `data/` |
| width, height | размер сохранённого файла (≤384 по длинной стороне) |
| orig_width, orig_height | размер скачанного исходника |
| bytes | размер сохранённого файла |
| sha1 | SHA-1 скачанного исходника — точные копии в разных объявлениях |
| phash | перцептивный хеш (64 бита, hex, совместим с `imagehash`). Расстояние Хэмминга ≤6–8 — то же фото после пересжатия или изменения размера |
| downloaded_at, attempts, error | состояние загрузки |

## Служебные таблицы

| Таблица | Содержание |
|---|---|
| runs | запуски: режим, время, статус (`ok`, `partial`, `blocked`, `error`, `interrupted`), полнота обхода выдачи, статистика (JSON) |
| errors | журнал ошибок: этап, URL, вид (`blocked`, `parse_error`, `unexpected_page`, `fetch_error`, `price_filter_ignored`, `slice_too_big`, `photo_failed`…) |
| search_slices | ценовые диапазоны выдачи в каждом запуске: сколько объявлений, сколько страниц обойдено |
